## 有效行为覆盖

- 入站缺身份、未装配、停止、拒绝、Future 失败/取消和接收器重装均明确结束，不回环旧 HTTP 或重复处理；公开兼容 HTTP 单独保留认证和授权。
- 真实授权、临时数据库与事务覆盖申请、HTTP 审批、规则执行、拒绝和撤权；独立平台使用自己的 provider、传输标识、连接和身份空间。
- 保留个人/群组/线程隔离、群组冒充拒绝、别名冲突、凭据轮换及脱敏、Web/WebAgent 保留身份、账号及连接同名重建隔离。
- Outbox 与各平台恢复用例验证冻结计划、稳定分段标识、已确认进度、未知结果、重试和发送前撤权复核。
- 旧插件公开入口通过显式兼容适配进入当前实现；SDK 门面不暴露私有证明、可信接收器装配或普通插件平台注册能力。
