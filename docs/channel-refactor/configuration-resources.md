# 渠道配置与规则服务

配置服务统一管理共享连接、通知路由和交互策略，各资源使用独立 revision。写入在同一配置事务内核对旧版本，成功提交后再对账客户端缓存并发布配置失效通知。

连接保存基础联通参数；平台表单约束、敏感字段和身份诊断交给对应模块。轮换必须核验同一平台账号，无法核验时保留已验证凭据并暂停实际收发。公开视图不回填密钥。

通知规则只在已限定受众内选择目标，不能扩大个人通知范围。发送窗口外直接跳过。规则匹配消费规范个人、会话和线程事实，不在公共服务解释平台地址。

删除移除完整连接资源，新建同名连接分配新 ID 与身份空间。正式升级使用固定离线算法；运行配置的兼容导入不替代数据库迁移。
