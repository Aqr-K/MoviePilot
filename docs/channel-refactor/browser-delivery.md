# 浏览器推送的登记与发送边界

网页登录证明设备登记的当前账号，应用服务绑定稳定通知身份和登记 revision。个人、所有用户和管理全体的目标选择使用明确账号集合，不读取历史无归属内存表；同名重建不能继承设备。账号目标格式与实际 WebPush 模块一起切换。

启动组合根同时装配订阅短事务服务和公网源站验证，关停时同时撤销，未就绪时不回退到旧表。协议发送只允许无凭据的 HTTPS 公网源站，禁用重定向；错误和日志不包含端点私有路径、查询令牌或浏览器密钥。

模块冻结设备版本和内容摘要，每次提交前复核账号和端点归属。旧 404/410 只删除当前匹配版本，429 保留设备并报告 Retry-After；未知响应不当作成功或允许盲目重发。普通消息和持久投递使用同一确认分类。

公开 REST 端点和登录、撤销及冲突状态见 `docs/mcp-api.md` 的浏览器设备章节。历史进程登记 ABI 仅保留给显式兼容调用，不能参与新的归属事实。
