# 渠道资源、认证入口与运行装配

连接、投递路由和交互策略共用版本化资源。管理端在同一配置事务核对 revision，启动层把资源投影为既有模块配置；连接改名保留稳定 ID，删除与同名重建不能复用旧身份空间。旧通知配置公开入口通过当前资源服务适配，通用系统配置入口只能读取受保护的管理投影。

启动层只装配既有模块目录、缓存对账、身份诊断、接收器和事件认领端口。具体协议认证、凭据约束、诊断和缓存内容由平台模块实现。停用连接的登录管理以保存的稳定 ID 定位，临时客户端关闭轮询并在请求结束或异常时释放。

已认证 SDK 入站沿以下调用链执行：平台协议认证 → 连接绑定提交 → 受管执行器 → 当前接收器生命周期复核 → 明确宿主 owner 解析 → 规范个人/群组/线程事实 → 公共审批、权限和规则 → 用例及写入前撤权复核。公开 HTTP 路径保留独立解析入口，丢弃客户端提供的可信标记；已关闭交互的连接不能改走插件解析器。

通知用例按稳定业务归属、明确受众及缺少操作用户策略选择路由，回复保留原会话和线程；平台负责目标编码和实际确认。分段计划与历史插件通知的认领由公共投递上下文传递。原全局自动下载配置已从活动配置模型和配置目录退出，搜索后的自动下载偏好由当前连接策略决定，实际下载仍独立复核权限。
