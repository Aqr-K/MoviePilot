# 宿主 SDK 绑定与统一模块派发

宿主模块按既有平台注册表绑定连接 ID、provider、身份空间、解析 owner 和策略 revision，再把只接收平台载荷的函数交给客户端。配置字典和载荷都不能覆盖该绑定。公共 SDK 保持版本化的类型门面，普通插件不取得绑定、接收器注入或可信证明能力。

已认证 SDK 事件只提交进程内接收器。缺少入口、身份或授权服务，停机、执行器拒绝、取消和异步失败均返回明确且脱敏的诊断，不切换 HTTP 路径。任务开始执行时再复核生命周期，旧接收器不处理新周期中的事件。同一已验证事件按连接认领，失败不通过另一条路径补投。

既有模块调度器使用明确宿主 owner 限制解析，不先交给插件或其他平台。平台只产生规范身份事实；审批、规则、业务归属与撤权复核仍由公共服务执行。强制私聊独立验证个人地址，清除群组和编辑上下文，不因发送未知或失败而回退到默认目标。

通知、交互回复、任务结果和审批回执按各自功能开关选择，冻结连接身份继续约束实际发送。旧公开 HTTP 适配保留为显式兼容用例，不能借此取得宿主 SDK 的信任来源。
