# 规范授权服务与仓储

平台在用例入口解析个人、群组、会话及可证明别名；领域只接受规范个人主体。授权服务独立复核连接身份空间、审批状态、账号归属、当前角色与操作权限，能力声明不授予权限。

仓储接收规范身份与查询条件，不在读数据库记录时解释平台协议。连接内多个记录命中同一别名时拒绝；跨连接的相同原始标识仍独立。管理员录入、账号关联和历史身份读取共用应用边界的规范化入口。

关联在同一短事务迁移稳定业务归属；待核对的旧用户名记录不自动认领。批量操作核对每个选择版本，任一冲突回滚整个批次，已授权删除必须确认。撤权后旧令牌与规则任务授权继续复核，不恢复旧授权引擎。

公开审批入口在提交事务中创建 Outbox 回执；受信 SDK 接收器、启动装配与业务副作用边界继续复核当前授权，公开兼容入口同样执行这些校验。
