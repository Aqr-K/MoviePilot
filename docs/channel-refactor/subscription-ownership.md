# 订阅的稳定业务归属

订阅与历史记录保存不可变账号身份，用户名仅用于展示。查询在分页与计数之前按身份限制，账号改名保留归属，同名重建不继承旧业务。

只有旧用户名的记录保留未确认状态。管理员确认使用订阅与目标账号各自的 revision，在同一请求事务中检查记录、账号和订阅唯一键；冲突回滚，不自动推断同名账号。

订阅完成时锁定最新记录，把当前已确认归属复制到历史；原订阅在准备期间被删除或归属锁失败时停止并回滚。账号关联只迁移已确认属于该成员的记录，不认领旁边的旧用户名记录。

本审核单元提供归属用例、持久化和可选查询参数，保留旧公开调用的默认行为。公开复核接口和请求主体注入将在对应 API 单元一起启用；下载上下文和任务跟踪在下载归属单元接入。
