# 平台扩展契约与装配

平台能力沿用宿主模块清单、能力注册表和模块分派器，不另建渠道注册中心。

- `ChannelPlatform` 描述个人与群组解析、地址编码、凭据约束和协议诊断；平台只产生事实。
- `ChannelActor` 表达规范个人主体及可证明别名；通用授权用例独立处理审批、权限和账号归属。
- `ModuleChannelCatalog` 从宿主清单生成惰性只读视图，枚举目录不会创建 SDK 客户端。
- provider 确定协议 owner；传输标识不隐含注册；连接 ID 和身份空间限制身份的使用范围。
- `app.sdk.channel` 第一版仅开放筛选后的类型和版本，不开放受信证明、入口注入或配置装配能力。
- Web/WebAgent 属于宿主保留身份，外部平台不能通过能力声明占用。

可安装插件渠道需要独立的信任模型。本轮稳定契约适用于宿主模块扩展，不授予普通插件宿主 owner 身份。

冷导入新增的事实仅为 `app.schemas.channel` 与 `app.schemas.delivery` 两个类型模块。启动快照记录这两项依赖，原 3000ms 上限保持；平台目录仍惰性加载，不初始化 SDK 或网络连接。
