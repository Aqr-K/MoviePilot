# 渠道扩展与架构验收

独立 platform:boundary-fixture 与全部 12 个内置平台共存，真实执行宿主注册、认证入站、申请、管理员审批、规则及拒绝链。协议和媒体业务终点使用隔离实现，授权、事务及仓储保留真实实现；不替换整个目录，不复用 Web/WebAgent。

可执行架构约束拒绝公共核心的平台协议依赖、局部别名及字典查表绕行，禁止宿主重新调用旧 HTTP helper；版本化公共 SDK 只导出筛选后的契约类型。可信绑定、接收器注入和 AdmissionProof 不作为普通插件 API。可安装插件渠道的信任模型不在当前宿主扩展合同范围内。

旧插件 helper 与必要类型导入按精确惰性别名兼容；旧公开 HTTP/API 和配置进入当前资源、revision、连接与权限校验。固定离线升级不访问平台网络或依赖运行时注册。
