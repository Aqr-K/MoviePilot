# 下载归属与提交前复核

已认证入口通过请求局部上下文传递稳定账号身份和可撤销授权检查。下载准备、提交事件之后及取得任务锁后均复核权限；事件和下载回调不能继承调用者上下文，失败时也恢复原请求状态。

仅新提交生成随机任务标识，同时写入下载器标签和下载历史。本人任务查询要求账号身份、任务标识、实际下载器和 Hash 全部匹配；多个标识、缺少匹配记录或仅 Hash 相同均不取得本人可见性。展示时隐藏内部标识，保留其他标签。

待确认下载保存脱敏的归属与提交标识，确认新任务时使用原始事实补记历史；确认已有任务时保留既有归属。旧历史不会因用户名相同而自动认领。订阅下载使用已确认的订阅归属，完成通知保留同一身份。
