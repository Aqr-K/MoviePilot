# 交互会话与可撤销业务上下文

每类交互状态按传输、稳定连接身份、个人、群组和线程存储，旧裸用户调用只访问独立本地空间。按来源更名仍可定位原稳定连接，同名重建不能取回旧状态。按钮还绑定候选快照和当前请求，消费使用同一把锁，旧按钮或重复写动作不能改变新状态。

媒体下载和订阅在实际副作用之前再次核验当前发言人的权限与业务归属。规则任务的授权上下文随宿主管理的任务传播；普通回复地址仅用于当前会话投递，不作为身份、审批或权限事实。已撤权的 Agent 选择不消费原请求，不启动后续操作。

回复上下文退出时恢复外层状态，不把群组地址当作个人接收身份；显式私聊要求不继承群组和线程。后台更新进度保留原交互地址，回调和私有任务结果仍独立执行当前授权复核。
