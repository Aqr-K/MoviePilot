# 冻结投递计划与分段恢复

公共投递服务冻结连接身份、规则快照和完整分段清单。平台提供规范目标、内容摘要及发送确认；通用服务不解释平台协议。预检阶段只准备清单，不调用网络发送。平台专属附件布局由对应平台实现返回，公共层仅处理通用图片与文件能力。

每段使用连接 ID、身份空间、目标和分段序号生成稳定标识。确认结果不被后续失败覆盖，未知结果不自动重发；明确失败可在内容未变时重试。连接、身份、目标或内容漂移均拒绝扩张原计划。旧持久化布局沿原始布局恢复，不重排已确认分段。

进度存储受 Outbox 当前认领版本保护，与业务事件快照分离。每次实际提交前核对规则发送时间，窗口外直接跳过；平台限流建议影响等待时间，但不能突破既有重试次数。旧插件无法确认外部副作用，同一次持久通知仅认领一次旧派发。
